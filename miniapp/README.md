# Daitora Vlog Box 微信小程序

用微信开发者工具导入本目录即可运行。上传用户按“创建素材包 → 选择文件 → 上传/重试 → 提交给剪辑师”工作；剪辑师端读取真实任务队列。

正式接入前需要：

1. 将 `project.config.json` 的 `appid` 替换为大寅集团的小程序 AppID。
2. 将 `app.js` 的 `apiBase` 替换为正式 HTTPS API 地址，并在微信公众平台加入合法域名。
3. 登录接口以 `wx.login` 的 code 换取会话，上传用户首次通过管理员邀请码绑定账号。
4. 大视频正式上传建议由 API 返回对象存储临时凭证或分片上传会话。
5. 后续如接入服务端生成的真实成品封面，可在成品接口返回受权限保护的封面地址；当前不打包示例封面。

登录通过 `https://api-vlog.daitora-jp.com/v1/auth/login` 完成，系统根据账号角色自动进入对应工作台，不需要用户手动选择上传工作台或剪辑师端。正式运营前必须在后台修改所有初始密码。
