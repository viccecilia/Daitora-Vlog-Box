# Daitora Vlog Box API

后端提供统一登录、独立拍摄素材包、受控状态流、成品版本、修改意见、站内待办、审计记录和授权下载。旧版按上传用户聚合接口继续保留用于历史兼容。

## 测试

```bash
python -m unittest discover -s tests -v
```

正式升级前必须按 `migrations/README.md` 备份数据库和媒体目录。migration 首次启动自动执行并记录版本，不删除旧表、旧字段或历史文件。

生产入口：`https://api-vlog.daitora-jp.com`

视频暂存在 VPS，应用层不限制单文件大小。实际可上传容量仍受 VPS 剩余磁盘、反向代理和客户端平台限制；正式运行前建议替换为对象存储直传。首次初始化必须通过环境变量设置管理员、剪辑师和上传用户口令；未设置时系统使用不可预测的随机口令。
